Deskripsi Project

Project ini dibuat sebagai latihan pembuatan website menggunakan HTML dan CSS. Pada project ini saya membuat halaman biodata diri dengan tampilan modern dan responsive.

Dalam pembuatan website ini, saya belajar bagaimana mengatur layout, warna, gambar, dan typography agar tampilan website menjadi lebih rapi dan nyaman dilihat.

Saya juga belajar mengenai penggunaan card layout, flexbox, serta desain responsive agar website dapat dibuka dengan baik di laptop maupun HP.

Melalui project ini, saya menjadi lebih memahami dasar-dasar pembuatan website dan semakin tertarik untuk mempelajari dunia pemrograman web.
