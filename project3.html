Project 3

Website Branding Popcorn BangJes

Project ini merupakan website branding produk popcorn bernama BangJes. Website ini dibuat untuk memperkenalkan identitas brand, varian rasa, tampilan produk, dan media promosi secara menarik.

Melalui website ini, pengunjung dapat melihat konsep visual dari brand popcorn BangJes, mulai dari logo, daftar menu, sampai video branding yang dibuat sebagai bagian dari promosi produk.

Branding Produk Varian Rasa Video Promosi

Deskripsi Project

Website branding popcorn ini dibuat menggunakan HTML dan CSS dengan tampilan yang modern, rapi, dan mudah dibaca. Tujuan utama project ini adalah menampilkan produk popcorn BangJes sebagai brand makanan ringan yang menarik untuk dilihat oleh calon pembeli.

Di dalam website ini terdapat informasi mengenai produk, visual logo, beberapa varian rasa popcorn, serta video branding. Project ini juga melatih kemampuan dalam menyusun layout, mengatur gambar, warna, typography, dan membuat halaman website yang responsive.

Dengan adanya website ini, brand popcorn BangJes terlihat lebih profesional karena memiliki media digital sederhana untuk memperkenalkan produk kepada orang lain.
